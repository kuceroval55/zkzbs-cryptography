# 🔒 ZKZBS – Základy kryptografie a bezpečnosti systémů

Ahoj! V tomto repozitáři najdeš má řešení úkolů a cvičení z předmětu **ZKZBS**.

Projekt slouží jako přehledný archív všech vypracovaných zadání – od klasických šifer a frekvenčních analýz až po pokročilejší kryptografické koncepty.

---

## 📂 Co tu najdeš?

Každý úkol má vlastní složku, ve které je zdrojový kód k řešení, vstupní data a stručný popis postupu:

- **`01_vigenere/`** – Prolomení Vigenerovy šifry pomocí frekvenční analýzy v Pythonu.
- _(další úkoly budu postupně doplňovat během semestru)_

---

## 🛠️ Jak skripty spustit?

Všechny úlohy jsou psané v **Pythonu 3**. Stačí przejít do složky daného úkolu a spustit skript:

```bash
cd 01_vigenere
python solve.py
```
